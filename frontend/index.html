How CRI works

  1. Each crime category is percentile-normalized across all States/UTs for the selected year, producing a score from 0–100.
  2. Equal weights are assigned to all seven crime categories because the project brief does not specify category-specific weights.
  3. CRI = weighted sum of the percentile-normalized crime scores, resulting in a 0–100 relative risk-position score.
  4. States/UTs are classified as Low, Medium, or High Risk using the 33rd and 67th percentiles of the CRI distribution.
